# Clipboard Landing Page

A responsive Clipboard landing page built with HTML and CSS.

## Live Demo

[View Live Website](https://kailashsaini-dev.github.io/clipboard-landing-page/)

## Features

- Responsive design
- Desktop, tablet, and mobile layouts
- Responsive two-column section
- Responsive workflow section
- Company logos section
- Download buttons
- Responsive footer
- Social media links
- Hover effects
- Mobile-friendly layout

## Built With

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- CSS Custom Properties (Variables)
- Responsive Web Design
- CSS Transitions
- Hover Effects
- CSS Box Shadow
- CSS `aspect-ratio`

## About the Project

This project was created to practice building a responsive landing page from a provided design. The layout adapts to different screen sizes for a better user experience.
